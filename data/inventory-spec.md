# 재고 관리 및 쿠팡 자동 발주 규격서 (inventory-spec.md)

## 1. 개요
공탄 노션(Notion) 재고 관리 데이터베이스를 바탕으로 매일 밤 11시(23:00) 부족 품목을 감지하고 쿠팡 장바구니 매칭 및 대표님 승인 카드를 통해 발주를 완료하는 규격입니다.

## 2. 노션 DB 스키마 규격
- **품목명 (Title)**: 예) 니트릴 장갑 L, 물티슈 100매, 연탄집게 등
- **매장 (Select)**: `1호점(인덕원)`, `2호점(백운호수)`
- **현재고 (Number)**: 현장 마감 실사 수량
- **적정재고 (Number)**: 최소 안전 재고 수량
- **발주필요 (Formula/Checkbox)**: 현재고 < 적정재고
- **발주수량 (Number)**: 권장 주문 수량
- **구매링크 (URL)**: 쿠팡 상품 링크 (선택 사항)
- **상태 (Status)**: `정상` / `발주필요` / `발주완료` / `입고완료`
- **최근주문일 (Date)**: 최종 발주 실행 일시

## 3. 쿠팡 품목 매칭 로직 (대표님 절대 원칙)
1. **동일 브랜드 · 동일 스펙 · 동일 중량(g)/용량 엄수**: 임의로 타사 저가형 브랜드나 PB 상품으로 대체하지 않고, 과거 구매 이력과 **완벽히 똑같은 브랜드, 똑같은 스펙, 똑같은 그램(g)**을 기준으로 매칭한다.
2. **동일 기준 내 실시간 최적화 탐색**: 동일 브랜드·동일 스펙·동일 그램 기준을 철저히 유지한 상태에서 쿠폰 할인, 대용량/다묶음 특가, 무료배송 등 가장 단가가 저렴한 최적화 상품을 매칭한다.
3. `구매링크` 컬럼에 URL이 있는 경우: 해당 URL의 상품을 우선 로드.
4. `구매링크` 컬럼이 비어 있는 경우:
   - 피클이 쿠팡 계정의 '주문목록(구매 히스토리)'에서 품목명을 키워드로 검색.
   - 직전에 주문했던 동일 브랜드, 규격, 옵션 상품을 찾아 장바구니에 매칭.

## 4. 발주 프로세스
```text
[매일 23:00 정기 실행]
       │
       ▼
[노션 재고 DB 스캔] ─── (부족 품목 없음) ───► [조용히 종료: silent]
       │
       ▼ (부족 품목 있음)
[쿠팡 상품 매칭 & 예상 견적 산출]
       │
       ▼
[대표님 카카오/채팅 발주 승인 카드 발송]
       │
       ▼ (대표님 [발주] 탭)
[피클 쿠팡 브라우저 즉시 결제 실행]
       │
       ▼
[노션 DB 상태 '발주완료' 갱신]
```
