# 공탄(Gongtan) 중앙 운영 제어 시스템 (SSOT)

외식 브랜드 **공탄(Gongtan)**의 전사 운영 규격, 매뉴얼, 비즈니스 룰 및 AI 에이전트(Claude, GPT, Pickle) 공용 단일 진실 공급원(Single Source of Truth) 저장소입니다.

## 1. 매장 현황
- **1호점 (인덕원공탄)**: 상호 공탄소갈비 / 사업자 271-02-01546 / 대표자 김경환 / 경기도 안양시 동안구 인덕원로 30, 1층
- **2호점 (공탄프라이빗 백운호수점)**: 상호 공탄 프라이빗 백운호수점 / 사업자 316-42-01151 / 대표자 이해리 / 경기도 의왕시 학현로 170-34, 1·2층

## 2. 3대 AI 에이전트 협업 구조
- **클로드(Claude)**: 전략 기획, 장부 심층 분석, 복잡한 시스템 로직 설계, 대규모 매뉴얼 고도화
- **GPT**: 실시간 가벼운 질의응답 및 외부 커스텀 액션 연동
- **피클(Pickle)**: 현장 실행 총괄 (구글 드라이브 장부 정리, 관공서 서류 발급, 쿠팡 자동 발주 및 매일 23:00 얼랏, 깃허브 자동 커밋/푸시)

## 3. 저장소 디렉터리 구조
```text
gongtan-ops/
├── CLAUDE.md                 # 전사 운영 대원칙 (숫자 임의생성 금지, 5단계 검산 체인)
├── README.md                 # 시스템 개요 및 에이전트 협업 가이드
├── rules/                    # 세부 비즈니스 룰
│   ├── verification.md       # 장부 판독 실패 시 null 원칙 및 결제일 규칙
│   └── settlement.md         # 가계/사업비 분리 및 외상 관리 원칙
├── manuals/                  # 현장 운영 매뉴얼
│   ├── counter.md            # 카운터 응대 표준 매뉴얼
│   ├── kitchen-prep.md       # 주방 프렙 및 소스 배합 규격
│   └── closing-report.md     # 마감보고 표준 서식
└── data/                     # 데이터 스키마 및 자동화 규격
    ├── inventory-spec.md     # 노션 재고 관리 및 쿠팡 매일 23:00 발주 스키마
    └── purchase-ledger.md    # 매입장부 및 확인대기 큐 처리 규격
```
